Stride Memory Access

A PyTorch tensor view is described by shape plus strides. This visualizer shows how row * stride_dim0 + col * stride_dim1 turns logical row and column coordinates into memory offsets.

Offset calculation

For each logical element, multiply the row index by the row stride and the column index by the column stride, then add those two terms.

offset = row * 4 + col * 1 row 0 offsets [0, 1, 2, 3]

For row 0, each column plugs its own column index into the offset formula.
