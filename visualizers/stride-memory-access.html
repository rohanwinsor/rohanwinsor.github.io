Stride Memory Access

A PyTorch tensor view is described by shape plus strides. This visualizer shows how row * stride_dim0 + col * stride_dim1 tuns logical row and column coordinates into the address vector passed to a Triton tl.load.

Tensor layout

Start with contiguous, then try larger column strides to see gathered loads.

offset = row * 4 + col * 1 row 0 loads [0, 1, 2, 3] 
row_ptrs = x_ptr + row_index * stride_x_row + col_offsets * stride_x_col

Each lane gets one address. tl.load(row_ptrs) loads from the whole vector of addresses.
